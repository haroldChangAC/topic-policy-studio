# Humanities & Policy Text Studio 使用手册

V0.1 双语个人研究试用版 · 2026-11-17

**保存提示**　关闭、刷新页面或重新建模前，请到左栏「保存与导出」，选择「项目 ZIP」，点击「准备导出」和「下载已准备文件」。主题分析的运行目录只自动存放导入文件和运行记录。政策评价在本模块的「保存与导出」直接点击「下载政策评价项目 ZIP」。

## 1. 工作台适合做什么

主题分析可帮助浏览和比较较多的人文文献、政策文本或新闻报道。请先检查语料来源和记录单位，再结合原文解释机器主题。基本 PMC 评价适合研究者定义指标、人工编码并对照政策文字。它的评价单位是整份政策。主题建模的单位是文本片段，两套项目可以各自保存和恢复。

左栏的「工作模式」提供新建分析、打开已有项目和基础政策评价。打开或完成项目后，「本页导航」可直接跳到当前项目的原文、图表、年度分析、编码或保存区。不显示左栏时，先展开页面左上角的侧栏。表格可在自身范围内滚动；长原文在可滚动文字框内显示，可复制全文。

## 2. 系统要求和第一次启动

本机验证于 Apple Silicon macOS、Python 3.11.18、Streamlit 1.66.1。项目使用已有 `.venv/`，依赖版本由 `uv.lock` 锁定。模型由 `models/model-lock.json` 锁定，当前为 `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`，向量维度 384。新建主题分析需要 `models/cache/` 中的完整模型。打开现有项目可直接查看已保存结果。

在这台已经安装的电脑上，双击项目中的 `启动工作台.command`，或在项目目录运行：

```bash
bash scripts/start.sh
```

在浏览器打开 [http://127.0.0.1:8501](http://127.0.0.1:8501)。服务使用本机地址，默认启用模型离线模式。只有在另置一套安装且获得安装和联网授权时，才需要依次执行 `bash scripts/setup.sh`、`bash scripts/download_model.sh` 和 `bash scripts/check.sh` 来建立并核对运行环境。已有项目可直接运行 `bash scripts/check.sh` 排查缺失。图表优先使用本机中文字体。

保存下载后，可在启动服务的终端按 Control+C 关闭。下次照原步骤启动并上传已保存的 ZIP。若提示拒绝连接，先检查启动终端是否仍在运行，及显示的实际端口。如果 8501 已被占用，先用 `lsof -nP -iTCP:8501 -sTCP:LISTEN` 识别服务。可另用 `bash scripts/start.sh --server.port 8502` 并打开 [http://127.0.0.1:8502](http://127.0.0.1:8502)。

## 3. 数据准备、导入与检查

在左栏选「新建分析」，上传最多 10 MiB 的 CSV、XLSX 或 TXT。先核对正文列及预览，再开始分析。

| 格式 | 准备方式 | 注意事项 |
| --- | --- | --- |
| CSV | CSV 表头用唯一、非空列名，每条记录一篇文档 | 推荐 UTF-8。也可选 GB18030 或 UTF-16。多行正文放入正确引号包围的字段 |
| XLSX | 选择工作表，第一行是列名，每条数据行一篇文档 | 正文公式须有已保存的缓存值。工作台读取缓存。请在 Excel 中重算、保存或粘贴为值 |
| TXT | 每个文件是一篇文档，选择正确的编码 | 保留解码后的空格、标点和换行。UTF-8 BOM 是编码标记 |

可使用 `title`、`text`、`year`、`group`、`source` 这样的列名。年份列填可核对的四位年份或明确日期，分组列可填地区、来源或其他可比较类别。保留来源用于原文回查。文件名或正文中的数字不会被推断为年份。预览最多展示前 100 条，分析使用完整文件。

空白正文及去重排除的行仍在原始文档表中。重复指非空原文逐字相同。默认保留所有副本，可选择仅首条建模。更换文件、正文列或分析设置可能清除当前页面上的研究结果，请先下载需要保留的项目。

## 4. 长文本和原文位置

「超长时停止」会提示超限文档。「自动切分超长文本」先选自然段、句子边界，必要时继续切分，片段无重叠。当前向量模型每段上限为 128 token，包括特殊 token，界面会显示实际模型检查结果。原文保留空白和标点，不会因切分而截断或覆盖。

文档是一个输入记录，片段是建模单元。到「主题与原文」，先按主题查看，再选片段和展开全文。文档 ID 保存源记录，片段 ID 保存这一段的引用。位置使用从 0 开始的 Unicode 字符索引，起点包含、终点不包含。例如在 `ABCDE` 的 `[1,3)` 是 `BC`。提取时使用原文，不使用经过排版或重编码的副本。

## 5. 本地 BERTopic、参数与关键词

1. 可首选 CPU。Apple Silicon 可选 MPS 计算嵌入，降维和聚类仍在 CPU。
2. 原有分词保留原试用版的 jieba 行为。中文分词保留单字，过滤单独标点，支持自定义词典。英文分词适合英文关键词，保留 ASCII 英文词、数字和词内撇号、连字符。它不保留汉字关键词，混合语料如需中英词可用中文分词。
3. 停用词默认关闭。可逐行编辑或上传 UTF-8 词表，启用时删除精确匹配的小写词。jieba 模式可编辑或上传自定义词典。英文模式下词典暂不启用。关键词分词影响 c-TF-IDF 表示，语义嵌入仍接收原始片段。先用分词预览检查术语。
4. 基础参数为 HDBSCAN 最小聚类规模，默认 4。高级 UMAP 邻居数默认 8，最小距离默认 0；HDBSCAN 最小样本数默认 2。邻居数影响降维的局部结构，最小距离影响图中点的紧密程度，聚类规模和最小样本影响成簇和离群。工作台按样本数校验参数。至少需 10 个片段、5 种不同片段。
5. 点击「开始主题分析」。随机种子固定为 42；在相同环境下便于复核。检查文档数、建模片段数、非离群主题数、离群片段和关键词，再选择片段并按 ID 回查。离群类是 `-1`。HDBSCAN 归属强度是模型输出，解释时区分主题重要性和校准概率。

该多语向量模型已在本机用合成英文和中英混合语料做流程测试。对特定领域、真实英文政策或不同语言的聚类质量应结合原文另外评估。

## 6. 命名与人工归组

「主题命名与归组」可以修改或清除显示名称，保留原主题编号和关键词。手动组由至少两个未归组的非离群主题组成。可修改组名和成员或解除组，修改历史随项目保存。未归组主题单列，离群类保持独立。主题组没有重新计算的 c-TF-IDF 权重。

归组片段数等于成员主题片段数之和。文档提及数按文档 ID 去重，例如同一份报告涉及组内两个主题时计为一篇。归组和重命名不会修改原始片段的主题分配。

## 7. 主题图表与原文回查

「主题图表」包含主题分布、关键词权重、主题相似度、向量层级和关键词共现网络。主题分布按片段计数。关键词权重使用实际模型 c-TF-IDF。相似度采用相同模型的主题向量余弦相似度；层级图使用距离 `1 − 余弦相似度` 和平均连接法。旧项目缺少权重或向量时相应图表不可用。

关键词共现默认以同一片段为单位，同一词对在一个片段内只计一次。可筛选范围和阈值，选择词对查看文本。节点使用出现片段数，连线使用共现片段数。各图说明对应的分母或权重。选择论文彩色或黑白、字号、尺寸和 DPI，再检查实际文件。部分论文图内的固定文字仍为中文。

## 8. 年度统计、分年建模和跨年相似性

- **年度统计**　指定年份／日期字段和可选分组字段。确定缺失、离群处理后点击「计算年度主题面板」。片段占比除以同年同组的纳入片段数。文档提及率除以同年同组至少有一个纳入片段的不同文档数。排除离群类时，纯离群文档不进入分母。一篇文档可以提及多个主题，所以提及率之和可能超过 100%。无样本或分母为 0 时比例留空；有样本但没有该主题时显示 0。
- **人工归组年度图**　切到人工归组视图，按年份、组和主题选择折线或热力图。核对折线时，到热力图的回查区选择同样的年份、组和主题，从表中选择片段。全语料按 ID 去重后汇总。无法解析的年份不绘入图。
- **按年份分别建模**　先做全语料建模，或打开包含建模片段的主题项目，再选择年份字段、年份和设备。每个年度独立建模。样本不足的年份会报告原因。同一主题编号只在一个年份内有意义，原全语料模型和年度面板同时保留。
- **跨年主题关联**　选相邻自然年份、主题、余弦相似度门槛和连线上限。缺失或失败的年份不跨越，离群主题不参与。正的余弦相似度是线宽权重，节点高度由相连权重决定，片段数和文档数另列。请选择一条关联核对两端主题和原文。它是语义空间中的相似性，研究者仍需核对历史延续和解释。

## 9. 基础 PMC、证据与模型辅助

1. 左栏选「基础政策评价」，导入并指定正文、标题及可选日期、机构、地区和来源列。已有项目可在政策模块恢复并追加文件，也可从已打开主题项目筛选文档，转入整篇原文及主题来源快照。
2. 在「指标体系」建立一级及二级指标、填写定义并确认。确认产生指标版本。之后可创建新草稿并确认新版本，已有编码留连到当时的版本。
3. 在「编码与证据」选政策和二级指标，选择 1（符合）、0（不符合）、待核查或不适用。填写证据和判断依据，选择精确定位时必须与 `[起点,终点)` 逐字一致。政策修订保留导入原文和历史版本。当前得分需要使用当前文本版本上有效的编码。
4. 每个一级得分为其二级指标的 1 值之和除以二级指标数。一级得分求和是原始 PMC，满分为一级指标数。10 分制为原始 PMC 除以一级指标数再乘 10。缺失、待核查、不适用及过时编码阻止完整总分。举例，三个一级得分为 1、0.5、0 时，原始分为 1.5/3，10 分制为 5。
5. 雷达图至少三个一级指标，可比较同指标版本下最多八份编码完整的政策，轴范围 0–1。基础 PMC 曲面要求恰好九个一级指标和完整编码，调整九格排列会改变位置。图上只有九个观测值，平面三角形用于连接相邻顶点。
6. 可选「模型辅助编码」连接已有的本机 Ollama 服务，默认 `http://127.0.0.1:11434`。使用已安装的模型名，例如既有试验中的 `qwen2.5:3b-instruct-q4_K_M`。先核对发送的范围再点击生成，避免将私有文本发送到可能转发云端的 Ollama 部署。长政策可建立分段任务并逐段或分批处理，查看已返回范围。证据精确匹配说明文字存在，仍需审阅其意义。建议可接受、修改或拒绝，正式编码才参与计算。

## 10. 文件准备、下载和重新打开

| 想保留的内容 | 在哪里操作 |
| --- | --- |
| 完整主题项目 | 「保存与导出」→「项目 ZIP」→「准备导出」→「下载已准备文件」。另存 `.hpts.zip`，左栏「打开已有项目」可恢复 |
| 主题表、文本、参数 | 项目区可直接下载若干 CSV／JSON。片段 CSV 和 Excel 在按需导出中准备 |
| 年度与跨年数据 | 图表区下载统计 CSV。导出区可准备年度建模数据 ZIP、跨年数据及图表 ZIP |
| 交互式跨年桑基图 | 解压「跨年关联数据及图表 ZIP」，在浏览器打开 `graph.html`。文件包含 Plotly 脚本。同一 ZIP 内有相似度、节点、连线和设置 |
| 图表 PNG／SVG／数据 CSV | 多数图表在图旁下载。跨年 PNG／SVG 在「保存与导出」按需准备。PNG 可用 150、300、600 DPI。SVG 中文通常为轮廓 |
| 政策项目和表格 | 在政策模块直接「下载政策评价项目 ZIP」；同区有 CSV 和多工作表 Excel。在政策模块选择「打开政策评价项目」，上传 `.pmc.zip` |

按需导出一次保留一个准备文件。修改主题名、归组或图表设置后，相关文件会失效，需再准备。可释放已准备文件。主题项目和政策项目的上传上限为 50 MiB。超长单元格或控制字符可能无法在 Excel 无损输出，此时使用 CSV 和 ZIP。图像超过 3600 万像素时缩小尺寸或降低 DPI；跨年静态图最多 30 个已连接节点、80 条线。

## 11. 双语和常见问题

- 左栏「语言 / Language」切换中文和英文。界面语言不会更改语料内容、列名、主题名称、关键词或已保存的记录。选英文界面后，仍需在关键词处理处单独选择英文分词。
- 空关键词结果通常与材料、分词或停用词有关。先检查预览；处理混合文本且需要汉字关键词时选择中文分词。
- 主题表里的字段名和方法记录保留原值。部分绘图固定注释、Streamlit 内置控件和原始后端诊断保留其原有语言。英文界面的未覆盖项见当前验证记录。
- 页面再次加载后若会话已消失，请从下载的项目 ZIP 恢复。只下载 CSV 或运行记录无法还原全部分析。

## 12. 版本、示例及限制

V0.1 支持读取主题项目 1–6 和政策项目 1–6。主题项目当前通常另存为版本 5，含分年模型时另存为 6。政策项目按内容选版本，有长政策分段任务时用版本 6。英文关键词设置随项目保存，较早的工作台无法使用该模式重算。主题项目保存分析结果，但不保存可继续训练的模型。

公开仓库包含合成导入示例。真实语料和个人项目文件请自行保存在本机。

当前没有情感分析、PMC-AE 或自动 Word 报告。独立桑基 HTML 的断网悬停和拖动仍缺少浏览器实测。跨年静态图与交互图共享数据，但布局不同。大文档和大量片段的 Excel 生成及下载可能消耗较多内存。浏览器内的研究修改，保存时应以新文件名下载并保留来源项目。
